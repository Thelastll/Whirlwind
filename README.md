### ДЛЯ ОБНОВЛЕНИЯ ПРИЛОЖЕНИЯ
Чтобы обновить программу скачайте новую версию, скопируйте со старой версии папки Files/ и Data/, перекиньте их в новую версию с заменой, после чего запустите UpdateData.bat. После этого все данные перенесутся на новую версию программы. Старую в таком случае можно полностью удалить. Также, при переходе на более раннюю версию нужно только перекинуть папки Files/ и Data/ с заменой, применять UpdateData.bat не нужно.

### Начало работы
Для начала необходимо ввести ipv4-адрес, принадлежащий к локальной сети.
ВАЖНО, передавать сообщения получится только в этой сети. Также чтобы принимать сообщения приложение должно быть постоянно запущеным.
Если адрес существует на компьютере, запустится основное окно.
Ip-адрес можно поменять нажав на соответствующую кнопку и ввести новый валидный адрес.

### Настройки
При нажатии на кнопку с шестеренкой откроется отдельное окно с настройками.
Они сохраняются автоматически, сразу после внесения изменений.

### Добавление собеседника
Для добавления нужно нажать на кнопку "+" и ввести уникальный ip-адрес и уникальное имя.
Для такого ввода не обязательно вводить существующий адрес, но чтобы сообщение дошло до адресата, адрес должен ему принадлежать.
Также при клике пкм по адресату его данные можно будет изменить или удалить.
Рядом с собеседниками в списке отображается в сети пользователь или нет, печатает он или нет, а также есть ли от него непрочитанные сообщения.
При клике ПКМ на адресата можно удалить или изменить его данные.

### Отправка и получение сообщений
При клике ЛКМ на адресата он будет выбран как текущий собеседник и ему можно будет отправить сообщение.
Сообщение прописывается в строке ввода, а файлы прикрепляются через отдельную кнопку рядом.
Также при нажатии сочетания ctrl+v, данные из буфера обмена будут прикреплены.
И при перетаскивании файла на основное окно, файл будет добавлятся в список ожидающих отправки.
При клике на кнопку отправить справа снизу или enter будет отправлено сообщение из строки ввода и все прикрепленные файлы.
Для добавления переноса строки в сообщение используется сочетание клавиш shift+enter.
При клике пкм на любое сообщение можно удалить его или копировать.
Для файлов также можно посмотреть их расположение. 
Отправленный файл не будет удалятся с компьютера в отличие от полученного.
А при копировании файла, он будет скопирован в буфер обмена.
Если кликнуть лкм по файлу, он откроется.
Любые изображения отображаются сразу при получении.
По ссылкам, начинающимся с http:// и https:// можно перейти.
Также в сообщении отображается отправлено/доставлено/прочитано.
Адресата можно заблокировать при нажатии на соответствующую кнопку справа-сверху.
При получении сообщения, если окно приложения было скрыто, оно откроется в Minimize режиме.
Если существуют непрочитанные сообщения, к значку приложения добавится крысный круг.

### Взаимодействие с уведомлениями
У конкретного адресата можно выключить уведомления или звук или все вместе при нажатии на соответствующую кнопку справа-сверху.
Громкость уведомлений можно изменить в настройках.
